ssterm bundles these fonts for offline use:
- Inter Variable, Fontsource package 5.3.0 — inter-OFL.txt
- JetBrains Mono Variable, Fontsource package 5.3.0 — jetbrains-mono-OFL.txt
- Noto Sans Thai Variable, Fontsource package 5.3.0 — noto-sans-thai-OFL.txt

The accompanying licenses are copied verbatim from the installed packages,
including their copyright notices. Font assets are emitted by Vite from the
package CSS imports. No font CDN or network lookup is used.
