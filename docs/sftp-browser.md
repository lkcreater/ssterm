## Files page

A **Files** page (sidebar, after Terminals) stays mounted like the terminal workspace and shows “This Mac” and a remote pane side by side in resizable halves. The remote pane opens one SFTP session per window from the host detail (“Open SFTP”), from a terminal pane menu (“Open in SFTP”, which captures that pane's host when clicked, so it uses the same saved host and identity) or from a server picker; choosing another host closes the previous browse-only session without a prompt. The remote pane uses the same session header as terminals (target, PROD, status, Copy target, Cancel/Disconnect/Close) and Reconnect re-lists the same folder. The status bar shows the remote target while the page is visible.

## Boundary

The renderer never touches the filesystem. `listDirectory`, `statPath` and `resolvePath` take a source (`local`, or a remote session and generation) and an absolute path; main fences remote calls by owner, session, generation, kind and Ready and returns file errors (not found, permission denied, invalid path, unsupported, failure, connection lost, resource limit, closed) inside the result without server text. Only `resolvePath` accepts `~`, `~/…` or relative input. Session lifecycle commands (`connectSftp`, `closeSftp`, `reconnectSftp`, `dismissSftp`) share one kind-checked helper with terminals, including the lock-epoch unlock. The local provider in main mirrors the read side of the SFTP capability: metadata only, explicit navigation only, 10,000 entries per listing, two local requests in flight for the whole app with a 10-second timeout that reports “The folder's volume is not responding”, and it stays available while ssterm is locked. A superseded busy reply is retried briefly so fast navigation does not end on an error.

## Names, paths and symlinks

Names are never normalized for addressing: APFS keeps NFD names verbatim and Thai mark order changes under NFC, so NFC is used only for sorting and type-ahead. Control, format (including zero-width and bidi), line and paragraph separator and tag characters, plus leading or trailing spaces, are shown escaped as `\u{…}` with a “contains hidden characters” marker (ZWJ, ZWNJ and variation selectors are kept so emoji and scripts render); names that do not decode are shown as “(unreadable name)” and cannot be opened or selected; copying uses the raw name. Symlinks show a Link icon and text and are followed only when opened: a folder opens at the link's own path, a file is selected, and a missing or looping target is reported as a broken link. Hidden (dot) files are toggled per pane.

## Keyboard and layout

Each pane is one listbox with an active descendant: arrows, Home/End and Page keys move; Enter or ⌘↓ opens; ⌘↑ or Backspace goes up; typing jumps to a name; Space, ⇧ and ⌘-click select; ⌘A selects all; ⌘C copies full paths; ⇧⌘G goes to a typed path; ⇧⌘. toggles hidden files. Rows are windowed at 32 px so a 10,000-entry folder renders about two dozen rows. Columns are Name, Size and Modified (a short date in narrow panes), with permissions in the tooltip and the detail line. Long names keep their last twelve characters visible so names with a shared prefix stay distinguishable, and the footer shows the focused entry's full escaped name. The footer counts visible items and hidden files separately. Selection snapshots `{source, path, names}` for SST-021.

## Verification

Final source: `npm run typecheck` PASS, `npm test` **348/348**, `npm run build` PASS, `npm run test:e2e` **51/51**, `npm run package:mac` PASS (unsigned arm64), `npm run test:packaged` **48/48**.

Unit tests cover the file contract and bounds, owner/session/generation/kind fencing, the shared lifecycle helper, the local provider on temporary directories (NFD and Thai names verbatim, symlinks, permissions, the listing cap, aborts and timeouts) and the browser library (escaping every invisible class including astral tag characters, paths and breadcrumbs, permissions, sorting, type-ahead with NFD/NFC, selection, windowing, reply fencing and tail-preserving truncation). [Browser E2E](../tests/e2e/sftp-browser.spec.ts) walks F04 against Docker OpenSSH in development and packaged builds: Open SFTP with trust and password, typed paths, Thai/emoji/NFD names, escaped and unreadable names, symlinks to folders and files and broken links, permission denied, the hidden toggle, a 10,000-file folder rendering under 30 rows with type-ahead to the last file, the local pane on a temporary folder, ⌘C of raw paths and Edit-menu Copy and Select All, keyboard-only use, Disconnect/Reconnect and lock re-listing the same folder, closing SFTP while the terminal stays Ready, server processes reaped, and “Open in SFTP” from a terminal reaching the same host even when another host with the same endpoint has a wrong username.

The independent tester confirmed the renderer has no filesystem or Node access, fencing refuses stale, foreign and relative requests, stale replies are dropped when switching hosts, protected home folders list without hanging, and quitting with only an SFTP session needs no prompt. Review found no critical/high; three mediums (invisible characters not escaped, a dead network mount able to stall shared I/O threads, a second Open SFTP failing silently) and the lows were fixed, as were the tester's indistinguishable long names, busy-after-fast-navigation, clipped breadcrumbs and focus after Open SFTP.

## Boundaries and rollback

There are no transfer buttons yet. Native ⌘C/⌘A routing through the macOS menu, VoiceOver, and the first-launch privacy prompt from Finder were not exercised. They are recorded as [deferred manual checks for SST-028](termius/tickets.md#sst-028--macos-package--release-readiness), together with the missing folder usage descriptions and the ad-hoc `Identifier=Electron` signature found in the packaged `Info.plist`. A hung network mount can still occupy a Node I/O thread after the timeout (a killable utility process is the recorded upgrade). Quit prompts list terminals only. Rollback removes the Files page, the file IPC and the local provider; terminal behavior is unchanged and there is no data change.

SST-022 adds per-file [Overwrite/Skip/Rename and staged publication](transfer-conflicts.md). Retained temporary paths and publication uncertainty are visible in the transfer queue; Clear finished affects history only.
