# ssterm 0.1.0 — release notes (local MVP)

**Platform:** macOS 13+ on Apple silicon · **Electron** 44.7.2 · **Signature:** ad-hoc (`dev.ssterm.desktop`), not notarized · **Install:** see [release guide](README.md).

## What's included

- **Servers:** hosts, nested groups with inherited port and identity, tags, Thai-aware search; PROD/STAGING/DEV labels everywhere a target is shown.
- **Identities and keys:** password, imported Ed25519/RSA keys (encrypted keys with optional saved passphrase), keyboard-interactive; secrets in the macOS Keychain only.
- **Trust:** unknown host keys always ask; changed keys block until you deliberately replace them; known-hosts list with revoke.
- **Terminals:** xterm.js tabs and splits, Unicode/Thai, paste safety, links, search, reconnect without replay, bounded flow.
- **Files (SFTP):** This Mac and remote panes, transfers with progress, cancel, explicit Overwrite/Skip/Rename and retained partial files.
- **Snippets:** encrypted bodies, name/tag search, Paste into a composer (sends nothing) and explicit Run to the captured terminal.
- **Port forwarding:** local tunnels on loopback with Start/Stop, typed bind errors, explicit restart on edit; never autostart.
- **Lock:** a screen lock or sleep closes sessions, tunnels and decrypted editors; the next explicit action unlocks.

## Known limitations

- **Not Developer ID signed or notarized.** First launch needs Open Anyway (macOS 15+) or Control-click → Open; after each upgrade macOS may ask again for Keychain access (choose Always Allow) and for folder access.
- The 16 px icon is not legible (32 px and up are); Dock/Finder icon review was not performed; the brand lockup is not shown in the About panel; the wordmark font is unverified. The About panel says "ssterm" while menus use the bundle name "SSTerm".
- Manual checks pending: physical Thai IME layouts, VoiceOver, real menu ⌘C/⌘A/⌘V, TCC prompts when launched from Finder; physical lock/sleep end to end.
- Tested on one macOS 15.7 arm64 machine; no clean VM or other macOS versions.
- Carried lower-priority issues are listed in the [MVP gate](../mvp-gate.md#unresolved-lower-priority-issues-carried).
